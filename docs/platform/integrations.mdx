# Integrations

The [integration catalog](https://www.appconnecthq.com/integrations) is generated
from AppConnect's current service definitions and lists every service with its
tools. It includes OAuth, API-key, and credential-form services.

Use a service's slug (for example `google-calendar`, `slack`, or
`github-oauth`) in `allowedServices`, `proxy`, and trigger calls.

A catalog entry is not a vendor endorsement or a production-readiness
guarantee. Confirm scopes, credentials, and supported operations during
private-beta onboarding.

## Request an integration

If a service you need isn't listed,
[request private-beta access](https://www.appconnecthq.com/early-access?from=sdk)
and include the service name and the workflow you have in mind. Never include
credentials in the request.
