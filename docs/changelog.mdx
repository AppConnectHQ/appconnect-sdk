# Changelog

Each SDK keeps its own changelog next to its source:

- [TypeScript: `@appconnecthq/sdk`](https://github.com/AppConnectHQ/appconnect-sdk/blob/main/typescript/CHANGELOG.md)
- [Python: `appconnect`](https://github.com/AppConnectHQ/appconnect-sdk/blob/main/python/CHANGELOG.md)

Both SDKs are released in two stages. A version is published to a staging
registry first (npm.w3api.dev or TestPyPI), then promoted to npmjs.com or PyPI
once it's verified.
